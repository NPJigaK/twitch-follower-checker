Twitch フォロワーチェッカーはソース公開型（source-available）のプロジェクトです。バグの報告や修正、新機能の提案、ドキュメントの改善など、どなたでも気軽に参加できます。

開発が初めての方も大歓迎です。気になった点や改善アイデアがあれば、ぜひ [Issue](https://github.com/NPJigaK/twitch-follower-checker/issues) でご意見やご提案をお寄せください。  
また、直接 Pull Request を送っていただくことも歓迎します。作業途中（Draft）の状態でも遠慮なくお送りください。

Pull Request を送る前に[コントリビューションガイドライン](https://github.com/NPJigaK/twitch-follower-checker/blob/main/CONTRIBUTING.md)をご確認ください。
機能改善や品質向上に協力して頂けますと幸いです。
